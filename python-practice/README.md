# Python Practice Scripts

Security-focused Python scripts I built while learning Python Basics.

## Scripts

### `brute_force_detector.py`
Detects brute-force login attempts by comparing failed attempts against a threshold.
Alerts when attempts exceed the limit and calculates a risk score.

### `access_control.py`
Access control system using boolean operators and conditionals.
Grants or denies access based on whitelist, account status, and failed attempts.


### `password_strength.py`
Checks if a password meets minimum length requirements.
Returns `True` if 8+ characters, `False` otherwise.
