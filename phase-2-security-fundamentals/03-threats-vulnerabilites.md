# Threats & Vulnerabilities

**Date started:** 2026-10-12
**Source:** Professor Messer Security+ SY0-701

## The Core Difference

- **Threat** = something that CAN cause harm (a hacker, malware, a hurricane)
- **Vulnerability** = a weakness that a threat can exploit (unpatched software, weak password)
- **Risk** = the chance that a threat exploits a vulnerability and causes damage

**Formula:**

If there's no threat, the vulnerability doesn't matter.
If there's no vulnerability, the threat can't succeed.

---

## Threat Actors (Who Attacks You)

| Actor | Skill | Motivation | Example |
|-------|-------|------------|---------|
| **Script Kiddie** | Low | Fun, ego | Uses existing tools |
| **Hacktivist** | Medium | Political/social | Anonymous |
| **Organized Crime** | High | Money | Ransomware gangs |
| **Nation-State** | Very High | Espionage, warfare | APT groups |
| **Insider Threat** | Varies | Revenge, money, accidental | Disgruntled employee |

**Attributes to note for each:**
- Skill level
- Resources available
- Motivation
- Where they operate

---

## Common Threat Vectors (How They Get In)

| Vector | What It Means |
|--------|---------------|
| **Phishing** | Fake messages that trick you into clicking/typing |
| **Social Engineering** | Manipulating people psychologically |
| **Malware** | Malicious software |
| **Unpatched Software** | Old bugs that still work |
| **Weak Passwords** | Brute-force targets |
| **Insider Threat** | Someone on the inside |
| **Physical Access** | Walking into a building and plugging in a device |
| **Supply Chain** | Attacking through a vendor or third party |

---

## Common Vulnerabilities (What They Exploit)

| Vulnerability | What It Means |
|---------------|---------------|
| **Unpatched Software** | Bug fixes not applied |
| **Misconfiguration** | Wrong settings, default passwords |
| **Weak Authentication** | No MFA, weak passwords |
| **Zero-Day** | Vulnerability with no patch yet |
| **Legacy Systems** | Old software still running (Windows XP) |
| **Human Error** | People clicking things they shouldn't |

---

## Key Takeaways

1. Threat + Vulnerability = Risk
2. Threat actors range from script kiddies to nation-states
3. The most common vector is phishing (attacks humans, not machines)
4. Most vulnerabilities are preventable (patches, MFA, training)
5. Insider threats are the hardest to defend against

---

## Cybersecurity Application

SOC analysts monitor for:
- Unusual login patterns (credential stuffing)
- Phishing emails reported by users
- Unpatched systems flagged by vulnerability scanners
- Insider threat indicators (off-hours access, data exfiltration)
